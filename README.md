# Controle-de-Estoque
< Programa desenvolvido para suprir necessidades básicas para o controle de um estoque (variado), com salvamento de arquivos em json e txt >

Funções :
- Cadastrar produtos
- Produto salvo automaticamente em .json
- Listar produtos, para facilitar o monitoramento dos produtos
- Busca por produtos (Id ou Nome)
- Movimentação de estoque, adicionando-os ou removendo-os
- Remoção de produtos cadastrados anteriormente
- Relatório total entre lucros e investimentos
- Relatório salvo em .txt
- Opção para sair e salvar todos os arquivos pendentes

Obs : 
Para que o código funcione, ambos os arquivos .py devem estar na mesma pasta, para que consigam conversar entre si
e importar as suas informações (funções)
